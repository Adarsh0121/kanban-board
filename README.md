# Kanban Board

A simple Kanban task board where you can add tasks, drag them between columns, and delete them. Built with HTML, CSS and JavaScript, no frameworks.

## Features

- Add new tasks with a title and description
- Three columns: To-do, In Progress, Done
- Drag and drop tasks between columns
- Live task count in every column
- Delete tasks
- Tasks are saved in localStorage, so they stay after page reload

## Tech Stack

- HTML5
- CSS3 (CSS variables, flexbox)
- JavaScript (DOM manipulation, Drag and Drop API, localStorage)

## How to Run

1. Download or clone this repository
2. Open `index.html` in your browser

## What I Learned

- Working with the HTML Drag and Drop API
- Saving and loading data with localStorage
- DOM manipulation using JavaScript
